# Setup

Use Xcode 26.6+ with Swift tools 6.3. Open Package.swift or run swift test. The executable fixture example is independent of credentials. For a live example supply a valid access token acquired through your Sonos integration's backend and opt in with --live.

SPM product is SonosNetworking. Repository identity is sonos-swift-networking. Pin the exact release/commit in consumers. This package does not register an integration or host OAuth/webhooks.
