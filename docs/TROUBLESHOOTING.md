# Troubleshooting

401: refresh authorization through your backend. 403: integration permission or capability restriction. 404/group changed: refetch household groups. 429: bounded retries apply to reads; callers must decide whether a write can be retried. Decoding failure: retain a sanitized response fixture and compare its schema.

Older Xcode cannot read the tools 6.3 manifest. Upgrade the IDE; changing only the tools-version comment is not a compatibility fix.
